# Undangan Pernikahan Elegan

Starter website statis dengan HTML, CSS, dan JavaScript.

## File
- `index.html`: konten dan struktur halaman
- `style.css`: desain responsif
- `script.js`: countdown, tombol musik, dan formulir demo

## Sebelum dipublikasikan
1. Ganti nama mempelai, tanggal, waktu, alamat, dan nama orang tua di `index.html`.
2. Ubah tanggal countdown di `script.js` menjadi tanggal acara yang benar.
3. Ganti foto contoh dengan foto yang Anda punya izin untuk digunakan.
4. Perbarui tautan Google Maps ke alamat acara yang benar.
5. Tambahkan file musik legal di `assets/music.mp3` (buat folder `assets` terlebih dahulu).
6. Form RSVP saat ini hanya demo dan TIDAK menyimpan data. Hubungkan ke backend seperti Supabase sebelum digunakan sungguhan.
7. Ganti tautan video YouTube contoh dengan video yang benar.

## Menjalankan secara lokal
Buka `index.html` di browser. Untuk pengalaman terbaik, gunakan ekstensi Live Server di VS Code.

## Publikasi di GitHub Pages
1. Buat repository GitHub baru, misalnya `undangan-elegan`.
2. Unggah `index.html`, `style.css`, `script.js`, dan `README.md`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
6. Tunggu proses publikasi selesai. URL biasanya `https://USERNAME.github.io/undangan-elegan/`.

GitHub Pages bersifat statis; jangan meletakkan password, service-role key, atau rahasia backend di file JavaScript publik.
